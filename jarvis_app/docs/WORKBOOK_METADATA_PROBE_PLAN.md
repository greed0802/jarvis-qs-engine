# Workbook Metadata Probe Plan

This is a future-only plan for a sheet-name-only workbook metadata probe. The probe is not implemented in this version.

Allowed future scope: explicit file reference, explicit sheet-name-only approval, safe path review, audit snapshot, blocked-result handling, and a sheet-name list output shape.

Blocked in this version: workbook opening, sheet listing, workbook content reads, formula reads, cell value reads, style reads, dimension reads, range reads, table reads, defined-name reads, external-link reads, safe path resolver calls, openpyxl/pandas imports, endpoints, and runtime stores.
